## Discovery protocol (read this, not every module file)

When assembling an artifact, pick modules by scanning THIS index - match the user's
request against each component's **use when / keywords / intent (EN·KO·JA)**, then
confirm you have the data via **input**. Only AFTER choosing do you open
`reference/04-module-catalog.md` for the chosen module's full prop/CSS contract.
Do **not** read all module files up front.

- **section** - the `tools/build.mjs` JSON section `type` that renders it (`(manual)` = paste the module file by hand; see `reference/06-usage-guide.md`). Three builder-only sections have no module file: `prose` (Markdown body text - paragraphs, lists, tables, code), `device` (app-frame preview from raw HTML) and `html` (raw passthrough; `module`/`cssModules` pull in module CSS).
- **avoid when** - guard rails: when another module is the better pick.
- **input** - the minimal data the section needs; confirm you have it before choosing.
- Colors are always semantic tokens; SVG modules already carry `role/aria`; interactive ones auto-wire via `interactions.js` data-attributes (no custom JS).

## charts - quantitative visualization

### `kpi-grid` - Row of headline metric cards (value + label + delta + note) in balanced columns; the delta arrow shows direction and its colour shows meaning (tone).
`section: kpi` · `interaction: counter` · `variants: cards|inline|hero`

- **use when:** showing 2-6 top-line numbers like revenue, users, conversion at a glance; dashboard or report header needs a KPI/scorecard strip; each metric has a value plus an up/down delta versus prior period; want animated count-up emphasis on bare numbers (no trend line needed)
- **avoid when:** if each metric also needs an inline mini trend/sparkline → `stat-trend`; if you have a flat list of label:value rows rather than headline cards → `stat-list`; if values should be plotted as comparative bars across categories → `chart-bar`
- **keywords:** kpi, metrics, scorecard, stat cards, headline numbers, delta, count-up, summary tiles, big numbers
- **intent:** EN: show our key metrics at the top / make a KPI dashboard row / big numbers with up/down change / scorecard of headline stats · KO: 핵심 지표를 상단에 카드로 보여줘 / KPI 대시보드 요약 줄 만들어줘 / 주요 숫자랑 증감률 같이 보여줘 / 핵심 성과 카드로 정리해줘 · JA: 主要指標を上部にカードで見せて / KPIダッシュボードの行を作って / 大きな数字と前期比の増減を出して / ヘッドラインの数値をスコアカードで

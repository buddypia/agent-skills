## charts
- `kpi-grid` (`kpi`) - Row of headline metric cards (value + label + delta + note) in balanced columns; the delta arrow shows direction and its colour shows meaning (tone). _[kpi, metrics, scorecard, stat cards, headline numbers]_
- `stat-trend` (`stattrend`) - KPI card with headline value + delta plus an inline sparkline of the recent trajectory. _[sparkline, kpi, trend cards, metric trend, mini chart]_
- `chart-bar` (`chart (variant:bar)`) - Vertical bar chart comparing one value per category, with readable HTML axis labels, nice ticks, optional target line and highlighted bar. _[bar chart, column chart, comparison, ranking, categories]_
- `chart-line` (`chart (variant:line)`) - Line chart for a trend over an ordered axis — one series with area fill, or several series with legend and end labels; readable HTML labels, optional target line. _[line chart, area chart, trend, time series, trajectory]_
- `chart-donut` (`chart (variant:donut)`) - SVG donut composition chart with a center total and a legend showing each slice's share (and value); optional click-to-highlight legend. _[donut chart, pie chart, composition, share, percentage]_
- `chart-stacked` (`barstacked | areastacked`) - Multi-series part-to-whole chart: stacked/grouped/100% bars or stacked/100% filled areas with a shared x-axis and readable HTML labels. _[stacked bar, grouped bar, 100% stacked, stacked area, multi-series]_
- `gauge` (`gauge`) - Grid of radial gauge rings, each showing a single value against a target/max with a center readout. _[gauge, radial, ring, dial, percentage]_
- `radar` (`radar`) - Multi-axis radar/spider chart plotting one or more series across shared axes as translucent polygons. _[radar chart, spider chart, polar, capability profile, skills]_
- `funnel` (`funnel`) - Vertical conversion funnel: left-aligned stage bars with value, share of the first stage and step conversion from the previous stage. _[funnel, conversion, drop-off, pipeline, stages]_
- `progress` (`progress`) - Stack of labeled linear progress/meter bars (completion, budget, quota, capacity) with optional status tone per row. _[progress, meter, completion, percent, quota]_
- `chart-bullet` (`bullet`) - Goal-vs-actual bullet bars (Stephen Few): value bar over a track with a target tick and optional qualitative bands. _[bullet, bullet graph, target, goal, actual]_
- `heatmap` (`heatmap`) - Value-shaded matrix heatmap (a real labeled table) for cohort/activity/correlation/risk grids; intensity = accent color-mix. _[heatmap, matrix, cohort, correlation, risk matrix]_
- `cal-heatmap` (`calendar`) - GitHub-style contribution calendar: week columns x weekday rows, day cells tinted by a 0-4 intensity bucket with Less/More legend. _[calendar heatmap, contribution graph, github, streak, cadence]_
- `chart-scatter` (`(manual)`) - SVG scatter / bubble chart: points (or value-sized bubbles) on X/Y axes with ticks and axis titles, series colored --cat-1..5, optional median quadrant splits. _[scatter, bubble, correlation, distribution, quadrant]_
- `chart-waterfall` (`(manual)`) - SVG waterfall chart: a start bar, floating increment (+, success) / decrement (-, danger) bars rising from the running total, a final total bar (accent), dashed step connectors, and per-bar value labels. _[waterfall, bridge, variance, increment, decrement]_
- `spectrum` (`(manual)`) - One-dimensional spectrum / scale (pure CSS, no SVG): a diverging track labeled at both ends with one or more ▼ position markers placed at left:PCT%. For putting several things on a single axis. _[spectrum, scale, axis, continuum, positioning]_
- `treemap` (`(manual)`) - Area-proportional treemap (pure CSS, no SVG): categories become columns sized by share of the whole, inner tiles stack by height so tile area encodes value/total; each tile shows a label + value with a --cat-N wash. _[treemap, area, proportion, share, composition]_
- `boxplot` (`(manual)`) - SVG box-and-whisker plot: 3–5 vertical boxplots on a shared value axis with min/max whiskers, a Q1–Q3 box (--cat-N), a median line, optional outlier dots, and mono Y-axis ticks. _[box plot, box and whisker, distribution, quartiles, median]_
- `bump-chart` (`(manual)`) - SVG bump chart / rank trajectory: y = ordinal rank (1 on top), x = 3–5 time points; one polyline per item connects its rank at each point with a dot per vertex and a label at both ends, so line crossings read as overtakes. _[bump chart, rank chart, ranking over time, league table, position change]_
- `chart-area` (`(manual)`) - SVG stacked area chart: 2–3 series stacked over 5–7 time points as translucent color-mix(--cat-N) bands with visible top edges, x labels, y gridlines, and a legend. _[area chart, stacked area chart, cumulative, composition over time, trend]_
- `dot-plot` (`(manual)`) - Pure-CSS dot / range plot: one row per category with a min–max range bar and 1–2 value dots positioned by percent, plus a legend for the dot series (e.g. current vs target). _[dot plot, dumbbell chart, range plot, gap chart, cleveland dot plot]_
- `slope-chart` (`(manual)`) - SVG slope chart: two vertical axes (before/after) with one line per item connecting its two values; rising lines are success-tinted, falling danger-tinted, flat muted, and each end carries the item label + value. _[slope chart, slope graph, slopegraph, before after comparison, two point change]_
- `waffle` (`(manual)`) - Pure-CSS waffle chart: a 10×10 grid of 100 cells where each category fills a run of consecutive --cat-N cells (one cell = 1%), with a legend mapping color to label + percent. _[waffle chart, square pie, unit chart, percentage grid, part of whole]_
- `chart-bubble` (`(manual)`) - SVG bubble chart: a scatter where each point's radius encodes a third measure (e.g. market size), 5–8 labelled bubbles with translucent --cat-N fills, X & Y axes with ticks and titles, and optional dashed quadrant midlines — three dimensions at once. _[bubble chart, scatter with size, three variables, size encoding, magnitude]_
- `chart-combo` (`(manual)`) - SVG dual-axis combo chart: bars encode a primary measure on the left axis while an overlaid line + dots encode a secondary measure on a right axis, correlating two measures with different units on one canvas. _[combo chart, combination chart, dual axis, bar and line, secondary axis]_
- `histogram` (`(manual)`) - Pure-CSS frequency histogram: contiguous vertical bins (no gaps between bars) whose heights encode frequency, an x-axis of bin labels, and an optional dashed mean-marker line — showing the shape of a distribution. _[histogram, frequency distribution, bins, buckets, distribution shape]_
- `pareto` (`(manual)`) - SVG Pareto chart: descending count bars (left axis) with an overlaid cumulative-percentage line + dots on a 0–100% right axis and a dashed 80% reference rule — sorting causes so the vital few stand out (80/20). _[pareto, pareto chart, 80/20, vital few, cumulative percentage]_
- `progress-ring` (`(manual)`) - SVG circular progress rings: a grid of 2–4 rings, each a track circle plus a stroke-dasharray arc, with a big % number and a label — a compact circular percentage widget grid for dashboards, toned per ring with --cat-N. _[progress ring, circular progress, radial progress, percentage ring, completion]_
- `sparkline` (`(manual)`) - Compact multi-metric scan table: 3–5 thin rows, each with a label, current value, a tiny inline sparkline (per-row polyline SVG), and a ▲/▼ delta badge toned success/danger — many KPIs' now + recent shape in one dense block. _[sparkline, inline chart, micro chart, metric rows, trend badge]_
- `cohort-grid` (`(manual)`) - Pure-CSS retention cohort table: rows are monthly signup cohorts, columns are period offsets M0..M5, each cell shows a retention % with a background whose intensity scales via color-mix of --accent, staircased so newer cohorts have fewer observed cells. _[cohort grid, retention table, cohort analysis, retention curve, churn cohort]_
- `composition-bar` (`(manual)`) - Pure-CSS single 100% composition bar: one full-width strip split into cat-tinted segments (widths set inline as percents), each labeled, with a legend of values below; optionally stack a second bar to compare two periods. _[composition bar, 100% stacked bar, single stacked bar, part of whole, share]_
- `diverging-bar` (`(manual)`) - Pure-CSS butterfly / diverging (tornado) bar chart: a central spine of category labels with bars extending left for series A and right for series B, mirrored around the center, values at the outer bar ends. _[diverging bar, butterfly chart, tornado chart, population pyramid, opposing bars]_
- `leaderboard` (`(manual)`) - Pure-CSS ranked standings table: rows carry a rank badge (top-3 medal-tinted), a name, a horizontal cat-tinted value bar, the value, and a since-last movement indicator (▲2 / ▼1 / – in success/danger/muted). _[leaderboard, ranking, standings, top n, scoreboard]_
- `pictogram` (`(manual)`) - Pure-CSS icon-unit (ISOTYPE) chart: each row is a label plus a strip of repeated unit glyphs (● or a 人 glyph) where filled units are accent/cat-tinted and the rest dimmed, with a value readout like 7/10人. _[pictogram, isotype, icon chart, unit chart, pictograph]_
- `tag-cloud` (`(manual)`) - Pure-CSS weighted tag cloud: inline-flex tags that wrap, each sized by a weight class (.w1–.w5 mapped onto the type scale) and cat-tinted, with an optional count, making topic frequency readable at a glance. _[tag cloud, word cloud, weighted tags, topic cloud, keyword frequency]_

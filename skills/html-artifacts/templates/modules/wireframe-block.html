A hand-drawn, low-fi screen-flow editor. Each page can be reordered by dragging or with the arrow keys, and adjacent pages are auto-connected by arrows. Use "+ Add page" to grow the flow (from templates like Blank, Dashboard, Form, List + detail, etc.), and place elements from the palette (16 standard UI elements plus 2/3-column and card layout containers) by clicking or dragging. Elements can be dragged across pages too, and nesting them into columns or cards builds the kind of complex UI layout found in real products. Delete with ✕ or Delete, move with the handle / arrow keys, and edit labels and page titles in place by clicking (Enter to confirm). Switch the look with Theme (palette) and Design (Sketch / Clean / Blueprint / Mono). The page order, each page's element tree (including nesting and labels), and the arrow connections can be exported to JSON.
